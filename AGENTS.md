# Agent Instructions & Strict Rules

## Strict Safety & Collaboration Rules

1. **NO GIT PUSH WITHOUT EXPLICIT USER INSTRUCTION**
   - **DO NOT** push any code or commits to GitHub or any remote repository (`git push`) until the user explicitly and directly instructs you to do so in the chat.
   - Keep all commits and modifications strictly local to the machine.

2. **Local Development & Verification**
   - All server processes, builds, and tests must run in the local workspace.
   - Confirm local verification and status with the user.
